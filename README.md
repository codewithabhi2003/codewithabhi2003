### 🛍️ [ReWear — AI-Powered Pre-Loved Fashion Marketplace](https://rewear-dusky.vercel.app)

> *Replaced traditional search filters with a conversational AI layer*

| Feature | Details |
|---|---|
| 🤖 Hybrid AI | Groq (LLaMA 3.1) for text discovery + Google Gemini for vision-based price estimation |
| 🔁 Fault-tolerance | 3-key rotation + 2-model fallback chain per provider — zero downtime on quota exhaustion |
| 💬 Real-time | Socket.io bidirectional chat + in-chat negotiation engine (offer/counter-offer/decline) |
| ⚛️ Concurrency | Atomic MongoDB operations eliminating race conditions across 5 message types |
| 💳 Payments | Razorpay + HMAC server-side signature verification across 2 checkout flows |
| 🔐 Auth | JWT handshake middleware securing WebSocket connections before room entry |
| 🚀 DevOps | GitHub Actions CI/CD + Vercel + Render — zero hard-refresh failures in production |

**Stack:** `MongoDB` `Express.js` `React.js` `Node.js` `Socket.io` `Groq` `Gemini` `Razorpay` `Cloudinary` `JWT` `GitHub Actions`
